# Stardew Energistics (Nexus page draft)

*Inspired by Applied Energistics 2. Not affiliated with or endorsed by AlgorithmX2 or the AE2 team.*

Wire your farm into a computer network. Store everything on disks, let machines run themselves from storage, and ask the network to craft whole recipes for you, parts and all.

## Features

- **Copper Wire and Heavy Cable** on their own floor layer. Hide it under flooring or with the Network Wrench.
- **A computer you build:** a Computer Core with racks beside it. Storage Racks hold disks, Power Racks hold Battery Packs, and Crafting Racks run autocraft jobs.
- **Disks** from Copper (20 kinds) up to Prismatic (any number of kinds). Upgrading a disk keeps everything on it.
- **Network Terminal:** a searchable storage grid, plus crafting straight from storage.
- **Machine Links:** one Link runs every identical machine touching it. You pick the inputs, how much to keep back, and the hours it runs. Nothing runs until you set it up.
- **Shipping Link** to ship your extras every night.
- **Autocrafting:** request 5 Quality Sprinklers. The network smelts the bars in linked Furnaces, then crafts the sprinklers.
- **Linked buildings:** put a Network Port beside each building and run cable to the farmhouse. Every Terminal then sees everything.
- **Late game:** the Wireless Terminal, the Power Feed for Lightning Rods and Solar Panels, the Advanced Crafting Rack (cooking, keep-in-stock), and the Island Uplink for Ginger Island.
- **Unlocks through Maru's letters** as you progress. Tier gates can be turned off in the config.
- **Vanilla resources only.** Multiplayer and split-screen supported, with the host in charge.

## Requirements

- Stardew Valley 1.6.15 or later
- SMAPI 4.5.2 or later
- Optional: Generic Mod Config Menu

## Install

Unzip into `Stardew Valley/Mods`. In multiplayer, every player needs the mod, and everyone should have the same version.
