# M6 in-game test: whole farm and release

Use a test save with linked buildings from M5. Commands go in the SMAPI console.

## Setup

1. `se_unlock all`
2. `se_give AdvancedCraftingRack`, `se_give PrismaticDisk`, `se_give IslandUplink 2`, `se_give CopperWire 50`
3. Learn some cooking recipes (e.g. `debug cookingrecipe "Fried Egg"`) and put the ingredients in storage.

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | Place the Advanced Crafting Rack beside the farmhouse Core | Terminal > Autocraft now lists cooking recipes too |
| 2 | Autocraft a dish | It's cooked straight into storage |
| 3 | Pick Speed-Gro (or anything), set Make 20, press Keep 20 | "Keeping 20 … in stock"; the line above Jobs lists it |
| 4 | Sleep with fewer than 20 in storage | In the morning: "Keep-in-stock started 1 job(s)"; the job runs |
| 5 | Press Keep 20 again on the same item | "No longer keeping … in stock" |
| 6 | Autocraft with bars that can only be smelted in another building's linked Furnaces | Works with the Advanced rack (a plain Crafting Rack uses only its own building's Furnaces when that building has a rack) |
| 7 | Craft a Prismatic Disk from an Iridium Disk | Same items; the disk meter shows ∞ kinds |
| 8 | Wire on the Ginger Island farm: Island Uplink + a Chest Link chest. Second Uplink on the home farm cable (or in a linked building) | The island chest's items show in the farmhouse Terminal |
| 9 | With Generic Mod Config Menu installed: change Battery Pack power and Tier gates | Saved to config.json; new values used at once |
| 10 | Online co-op: a farmhand joins with an older/newer version | Both see a warning naming the player and both versions |
| 11 | Online co-op on two Steam Decks: the farmhand opens a Terminal in a linked building, takes and stores items | Works; the host sees the same storage |

**Done when** two Steam Decks share one linked farm in online co-op.
