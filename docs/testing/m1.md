# M1 in-game test: components and wire

Placeholder art is expected: coloured boxes for items, orange lines for Copper Wire, grey lines for Heavy Cable.

Use a test save, not your main farm. Open the SMAPI console window to type commands.

## Setup

1. Build (Visual Studio: Build > Build Solution, or `dotnet build` in the repo folder). The mod copies itself to `Mods`.
2. Start the game through SMAPI and load a test save.
3. In the SMAPI console type: `se_unlock all`
4. Give yourself materials: `se_give CopperWire 50`, `se_give HeavyCable 20`, `se_give NetworkWrench`, `se_give CopperProcessor 2`.
   For the press, use the game's own command: `debug item 334 10` (Copper Bar), `debug item 338 5` (Refined Quartz), `debug item 336 2` (Gold Bar).

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | Open the crafting menu | Processor Press, Copper Wire, Heavy Cable and Network Wrench are listed |
| 2 | Place a Processor Press, put in a Copper Bar | It takes the bar and one Refined Quartz and shows its working frame. Next morning: a Copper Processor |
| 3 | Put a Gold Bar in with no Copper Processor in your inventory | Red message saying what else it needs; nothing is used up |
| 4 | Go into a shed. Hold Copper Wire, click a floor tile | One wire appears, the stack goes down by one |
| 5 | Hold the button and drag | A line of wire; straight pieces join, corners and T-junctions look right |
| 6 | Click a chest with wire in hand | Wire goes under the chest; the chest does not open |
| 7 | Lay Heavy Cable next to Copper Wire | They join up |
| 8 | Hold the Network Wrench | All wire glows (Network View) |
| 9 | Wrench: tap one wire tile | It hides (only shows faded in Network View). Tap again: back |
| 10 | Wrench: hold on a wire tile for half a second | The whole connected run hides, with a message how many tiles changed |
| 11 | Wrench: right-click Heavy Cable a few times | It changes colour each time |
| 12 | Press F6 | Network View toggles on/off without the wrench |
| 13 | Pickaxe a bare wire tile | Wire pops out as an item |
| 14 | Lay a floor path or flooring on top of wire | The wire is hidden under it (still visible in Network View) |
| 15 | Sleep (save), quit to title, load again; type `se_wires` | Same wire, same joins, hidden/colours kept. The console lists the shed's tile count |

**Done when** check 15 passes on the PC and on a Deck.

If anything is wrong, upload the SMAPI log at https://smapi.io/log and share the link.
