# M2 in-game test: simple storage and basic crafting

Placeholder art: grey boxes for the Core and racks; a rack's box gets lighter and shows more teal dots as it fills.

Use a test save. Commands go in the SMAPI console.

## Setup

1. `se_unlock all`
2. `se_give ComputerCore`, `se_give StorageRack 2`, `se_give PowerRack`, `se_give NetworkTerminal`, `se_give CoalGenerator`, `se_give ChestLink 2`, `se_give CopperDisk 3`, `se_give CopperWire 50`, `se_give NetworkWrench`
3. `debug item 787 2` (Battery Packs), `debug item 382 20` (Coal), and some crops or ore to store.

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | In a shed, lay wire. Place the Computer Core **on** the wire. Place a Storage Rack and a Power Rack directly beside the Core | `se_graph` lists one network with the Core and both racks |
| 2 | Right-click the Storage Rack with a Copper Disk | Disk goes in, message shows "0/20 kinds". Rack sprite changes |
| 3 | Right-click the Power Rack with a Battery Pack | "1/4 Battery Packs, 100 power" |
| 4 | Place the Terminal on the wire; place a chest on the wire and right-click it with a Chest Link | "Chest linked" |
| 5 | Right-click the Core | Status: blocks, disks, kinds, power |
| 6 | Right-click the Terminal > Storage. Put items in, close | Items are now on the disk (`se_graph` shows kinds/items) |
| 7 | Terminal > Storage again; take some out | You get them back |
| 8 | Put 21 different kinds in with one disk | The 21st kind ends up in the linked chest (or back in your inventory) |
| 9 | Terminal > Craft. Craft something whose ingredients are only on the disk / in the linked chest | It crafts, the ingredients leave network storage |
| 10 | Right-click the Storage Rack with empty hands | The disk comes out. Put it in the other rack: same contents |
| 11 | Place a second Core on the same wire | Right-click the Core: red "Two Computer Cores" message |
| 12 | Put a rack one tile away from the Core | `se_graph` reports a rack-not-touching problem |
| 13 | Sleep. Next morning `se_graph` | Power went down by the daily use (7 for Core + rack + terminal + links) |
| 14 | `se_power` several times until under 3 days left | "x day(s) of power left" message once |
| 15 | Remove the batteries' power (keep running `se_power`) | "out of power" message; Terminal > Craft says paused; Storage still opens |
| 16 | Load Coal into the Coal Generator (placed on the wire) | "20 power of fuel loaded"; the network runs again |
| 17 | Sleep, quit, reload | Disks, rack contents, battery charge and chest links all kept |
| 18 | Coal Generator recipe | Check the crafting menu accepts a Furnace as an ingredient |
| 19 | Maru letter: `debug friendship Maru 500` then sleep | A letter from Maru with the Processor Press recipe |

**Done when** a shed network holds 20 kinds and runs two weeks on one Battery Pack (use `se_power` 14 times), and a farmhand in split-screen can take an item from the Terminal (farmhand support is still to come).

If anything is wrong, upload the SMAPI log at https://smapi.io/log and share the link.
