# M3 in-game test: machine automation

Placeholder art: the Links show as small grey item icons; nothing is drawn on the machine yet.

Use a test save with an M2 network (Core, Storage Rack with a disk, Power Rack with a Battery Pack, Terminal) in a shed. Commands go in the SMAPI console.

## Setup

1. `se_unlock all`
2. `se_give MachineLink 3`, `se_give ShippingLink`, `se_give IronDisk`, `se_give NetworkWrench`, `se_give CopperWire 50`
3. `debug item 12 6` (Kegs), `debug item 248` (Mini-Shipping Bin is a big craftable: use `debug bc 248`), and 30 Wheat (`debug item 262 30`), 10 Blueberries (`debug item 258 10`).

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | Put the Wheat and Blueberries in the network through the Terminal | Grid shows them |
| 2 | Place 3 Kegs touching each other, one of them on the wire. Right-click that Keg with a Machine Link | "Link attached" message, `se_graph` lists a MachineLink |
| 3 | Right-click a Keg with a Machine Link again | "This already has a Link" |
| 4 | Wait a game hour | Nothing happens: the Link isn't set up yet |
| 5 | Right-click the linked Keg with the Network Wrench | Settings open. Title says "Keg x3" |
| 6 | Click Wheat in your inventory, then Blueberries. Set Keep on Wheat to 10 (right-click + steps by 10). Close | Saved |
| 7 | Wait 10 game minutes | All 3 Kegs start (Wheat first). Wheat in storage never drops under 10 |
| 8 | Wait until they finish (or sleep) | Beer goes into network storage and the Kegs start again; when Wheat hits 10, Blueberries are used |
| 9 | Wrench > toggle Output to "leave in machine" | Finished Beer stays in the Kegs |
| 10 | Wrench > Runs: set hours to 6:00 PM to 2:00 AM | Kegs only get loaded in that window |
| 11 | Wrench > Copy; wrench another Link (on a separate Keg group) > Paste | Same settings |
| 12 | Remove the batteries' power (`se_power` until out) | Links stop |
| 13 | Place the Mini-Shipping Bin on the wire, right-click it with the Shipping Link, wrench it, add Blueberries with Keep 2 | Saved |
| 14 | Sleep | Morning: shipping summary includes the Blueberries above 2 |
| 15 | Wrench a Link > Remove | Link item drops; the machine is normal again |
| 16 | Craft an Iron Disk from a Copper Disk that holds items | The Iron Disk keeps the same items with bigger limits |
| 17 | `se_perf` | Prints machines handled and the time (should be well under 5 ms for 50 machines) |
| 18 | Sleep, quit, reload | Links and settings kept |

**Done when** a group of Kegs runs for a week from network storage with keep-back respected, and finished goods end up in storage.
