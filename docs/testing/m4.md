# M4 in-game test: autocrafting

Placeholder art: the Crafting Rack is a grey box that turns lighter while it works.

Use a test save with an M2/M3 network (Core, Storage Rack with a disk, Power Rack with a Battery Pack, Terminal) in a shed. Commands go in the SMAPI console.

## Setup

1. `se_unlock all`
2. `se_give CraftingRack`, `se_give MachineLink 2`, `se_give NetworkWrench`, `se_give CopperWire 30`
3. `debug bc 13 2` (2 Furnaces), `debug item 380 20` (Iron Ore), `debug item 384 20` (Gold Ore), `debug item 80 5` (Quartz), `debug item 382 20` (Coal)
4. Learn the Quality Sprinkler recipe: `debug craftingrecipe "Quality Sprinkler"` (or `debug ar "Quality Sprinkler"` on older debug builds)

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | Place the Crafting Rack beside the Core (or another rack) | `se_graph` lists it in the network |
| 2 | Put the ore, Quartz and Coal into the network through the Terminal | Grid shows them |
| 3 | Place both Furnaces touching each other, one on the wire. Use a Machine Link on that Furnace (no need to set it up) | "Link attached" |
| 4 | Terminal > Autocraft | Recipe grid shows items you know how to craft, plus smelted bars |
| 5 | Pick Quality Sprinkler, set Make 2 | "Ready to make. Uses: 10 Iron Ore, 10 Gold Ore, 2 Quartz, 6 Coal" |
| 6 | Start | "Job started", the Jobs list shows it at 0% |
| 7 | Wait 10 game minutes | Both Furnaces start smelting (ore and coal leave storage). Rack looks "working" |
| 8 | Wait until the bars finish | Bars go into storage, the Furnaces load the next step, percent goes up |
| 9 | When all bars are done | 2 Quality Sprinklers appear in storage, "Autocraft done" message |
| 10 | Ask for more than you have materials for | "Missing: …" in red, Start does nothing |
| 11 | Start a job, then Cancel it in the Jobs list | "Job cancelled"; any bars already in a Furnace still come back to storage |
| 12 | Two jobs with one Crafting Rack | The second shows "queued" until the first is done |
| 13 | Right-click the Crafting Rack | Message lists the jobs and percent |
| 14 | Start a job, sleep, quit, reload | The job is still there and carries on |
| 15 | Unpower the network (`se_power` until out) | Jobs pause |

**Done when** one request for a Quality Sprinkler smelts its bars from ore and crafts it.
