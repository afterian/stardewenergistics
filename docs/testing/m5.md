# M5 in-game test: linked buildings

Placeholder art: Network Ports are grey boxes (lighter once joined); the Wireless Terminal and Power Feed are small grey icons.

Use a test save. Commands go in the SMAPI console.

## Setup

1. `se_unlock all`
2. In the **farmhouse**, a **shed** and a **barn** (or any 3 buildings with an inside): build a small network in each (Computer Core, Storage Rack with a disk, Power Rack with a Battery Pack, Terminal). Put a few different items on each one's disk.
3. `se_give NetworkPort 3`, `se_give HeavyCable 200` (or `se_give CopperWire 200`), `se_give WirelessTerminal`, `se_give PowerFeed`, `se_give IridiumDisk`, `se_give NetworkWrench`
4. `debug bc 9` (Lightning Rod)

## Checks

| # | Do this | Expect |
| --- | --- | --- |
| 1 | Outside, lay cable on the tile right next to the farmhouse wall and place a Network Port on it | Right-click the Port: "Network Port joined to Farmhouse" |
| 2 | Same beside the shed and the barn; run cable from each Port to the farmhouse Port's cable | `se_graph` on the Farm lists one network with 3 Ports |
| 3 | Open the farmhouse Terminal | It shows items from all three buildings |
| 4 | Take an item that lives on the shed's disk from the farmhouse Terminal | It comes out; the shed Terminal no longer shows it |
| 5 | Store items from the barn Terminal until its disk is full | Extra items go to the other buildings' disks |
| 6 | Place a Port in the middle of the farm, not beside a building | Right-click: "Place the Network Port right beside a building" |
| 7 | Break the cable between the shed and the farmhouse | The farmhouse Terminal stops showing the shed's items |
| 8 | Use the Wireless Terminal outside on the farm | The Terminal opens with everything; inside the shed it opens too |
| 9 | Use the Wireless Terminal in town | "No network reaches here" |
| 10 | Put a Lightning Rod on the farm cable and use the Power Feed on it. On a stormy night (`debug setweather storm` or wait), let it charge | Next morning, the Battery Pack goes into a farmhouse Power Rack slot (if one is free) |
| 11 | A Machine Link on Kegs outside on the farm cable, set up with the wrench | The Kegs run from the combined storage using the farmhouse's power |
| 12 | Craft an Iridium Disk from a Gold Disk that holds items | Same items, bigger limits |
| 13 | Autocraft from the shed Terminal with ingredients only in the barn | Works (if the shed has a Crafting Rack) |
| 14 | Sleep, quit, reload | All links still work |

**Done when** the farmhouse Terminal shows items from three buildings.
