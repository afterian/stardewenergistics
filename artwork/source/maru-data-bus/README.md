# Maru data bus: animation study

The previous heavy cable read as a metal pipe. This prototype replaces the bands and round shading with a flat plum jacket, dark paired data windows, and small square junction displays. Thin amber traces visually link the devices to the wide trunk. This is an original design inspired by the idea of visibly active networks, not copied AE2 assets or the addition of channels.

The loop is 16 frames at 10 fps. The proof of concept drives the pulses by tile distance along an example graph; the core and terminal are the current native Maru exports. The unpowered comparison keeps the same silhouette with dark windows. This is a review animation on a schematic oak floor, not a simulation of throughput or an in-game capture.

If selected for production, keep the 16 mask silhouettes and isolate the animated pixels in separate overlay sheets. Tint the paintable jacket independently of the signal. Prefer a dim powered-idle display, local pulses when there are real machine events if available, and no signal when unpowered. Respect hidden wires and Network View. Test animation off/reduced motion and confirm the two wire weights at game zoom. No production PNG or mod code changed in this study.
